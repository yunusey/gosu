# Gosu

<div align="center">
	<img src="./icon.png" width="200" />
</div>

Welcome to Gosu, a basic game illustrating fundamental 2D game development features and concepts in Godot:
- Shaders
- 2D Mesh generation using GDScript
- Detecting input
- Scene instancing
- GUI (Graphical User Interface)
- Audio
- Custom Cursor
- Make HTTP requests
